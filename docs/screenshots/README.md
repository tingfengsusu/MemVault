# 面板截图与接口清单(可展示证据)

> **这些截图用的是演示数据,不是真实库**:脚本会在 `temp/demo_data/` 建一套独立的
> 临时数据目录(7 个演示条目 + 4 张生成的帧图 + 1 件商品主图),再另起一个服务
> (**端口 8899,不碰 8765 的真实库**)逐页截图。这样截图可以直接放进仓库/简历,
> 不会暴露你真实收藏的书与视频。

## 文件

| 文件 | 展示的内容 |
|---|---|
| `01-库首页.jpg` | 统计条、领域筛选、卡片网格(缩略图 / 语义块数 / 已分类 / 🔗 相关条目) |
| `02-待整理箱.jpg` | 批量操作条(已归类 / 归档 / 交给 AI)、领域筛选、单条操作与分类下拉 |
| `03-检索(含相关画面).jpg` | 文本混合检索结果 + 「🖼 相关画面」墙(Chinese-CLIP 文字搜画面),整页截图 |
| `04-分类管理.jpg` | 分类树(含"待确认"提议的采纳/删除)、UP主 → 分类规则 |
| `05-任务队列.jpg` | 任务列表 + 状态筛选(完成/失败/处理中/排队)与耗时 |
| `06-订阅源.jpg` | B站 UP主订阅(新增、启停、立即检查) |
| `07-设置.jpg` | LLM 通道/模型/阈值、测试连接、"当前生效配置"(整页) |
| `08-聊天.jpg` | 技能选择、欢迎语、输入区 |
| `09-条目详情.jpg` | AI 提取表、原始属性(UP主)、语义块时间轴(带 ▶ 跳到视频此处)、UP 绑定入口 |
| `../api.md` | **HTTP 接口清单**:30 个 JSON 端点(含中文说明)+ 24 个旧表单路由,由 OpenAPI 自动导出 |

## 重新生成

```bash
# 需托盘服务与真实库不参与;脚本自己起 8899 端口的演示实例
HF_HUB_OFFLINE=1 .venv/Scripts/python temp/make_evidence.py
```

脚本会:造演示数据(已存在则跳过)→ 起临时服务 → Playwright 打开 9 个页面
(**逐页断言关键文案都在**,避免截到白屏)→ 截图到本目录 → 导出 `docs/api.md`。
演示数据的图像向量用真实的 Chinese-CLIP 生成,所以"相关画面"是真实检索结果。
